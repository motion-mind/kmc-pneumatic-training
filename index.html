Try this

  1. Click the main-air line to the controller (port M) — the terminal fails to heat: the cold damper springs closed and the reheat / hot-deck opens.
  2. Switch Terminal type between Reheat coil and Dual duct to see the two box styles.
  3. Unplug a sensor line (H or L, top) — the controller can’t measure flow, so it drives the cold damper wide open.
  4. Switch to Reverse reset while the thermostat is direct-acting — the loop controls backwards and runs away.
